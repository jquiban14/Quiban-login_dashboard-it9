

## Project Description

This is a simple front-end web application created using HTML and CSS. The system demonstrates a basic Login, Registration, and Dashboard flow.

This project was created as part of our laboratory activity.

## Features

- User Login Page
- User Registration Page
- Dashboard Page
- Student Records Table
- Logout Navigation
- Consistent CSS design
- HTML form implementation
- Page-to-page navigation

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code

## How to use this?

. Open the Login Page

Open login.html in a web browser.

The Login page contains:

Username field
Password field
Login button
Registration link
2. Register an Account

If you do not have an account, click:

Register here

You will be redirected to the Registration page.

3. Register

The Registration page contains:

Full Name
Username
Email
Password
Confirm Password

Enter the required information and click the Register button.

After clicking Register, the application redirects back to the Login page.

4. Login

Enter a username and password, then click the Login button.

The application will redirect to the Dashboard.

5. Dashboard

The Dashboard displays:

Welcome message
Student records
Student ID
Student Name
Student Email
Student Course
6. Logout

Click the Logout button to return to the Login page.

User Manual
